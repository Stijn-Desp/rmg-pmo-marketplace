# rmg-pmo

Four skills covering the Roularta PMO gates. See the repository README for how
the gates connect, how to install, and what is still unconfirmed.

Each skill is triggered by the vocabulary people here actually use — "PID",
"plan to execute", "PTE", "plan van uitvoering", "closing doc", "what do I need
for the PMO Board" — including when someone asks for only one of the documents.

The skills never invent an internal fact. A field they were not given becomes a
visible marker in the deck:

```
⟨MISSING: Business case — owner: Business Controlling — needed by: before the gate⟩
```

That is deliberate. A complete-looking deck built from incomplete input is worse
than an obviously unfinished one.
