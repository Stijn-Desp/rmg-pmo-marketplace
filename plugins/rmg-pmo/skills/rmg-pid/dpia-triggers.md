# DPIA triggers (from the PID template)

Read this when deciding whether the project needs a Data Protection Impact
Assessment, or when the user asks why the skill flagged DPIA.

A DPIA is required in the following cases:

- an automated evaluation / profiling of the personal aspects of an individual
- processing of sensitive data, for example: biometric data, information
  collected from third parties, health data, information about income,
  behaviour, preferences and interests, location or movements, private
  activities, data generated by sensors, telephony, internet or other
  communication data
- systematic monitoring of public spaces
- matching or merging of datasets containing personal data

For questions or help performing the DPIA, contact **Peter Thiers**.

## How the skill uses this

Scan the project description, scope, and the data the project touches. If any
trigger plausibly applies and the PID's DPIA answer is "no" or missing, treat it
as **blocking** and name the trigger that fired. Do not decide the DPIA outcome
yourself - the skill's job is to make sure the question was actually asked and
answered by someone who can answer it.
